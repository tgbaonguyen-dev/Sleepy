# Sleep — Nghỉ

Hẹn giờ tắt máy, ngủ, khoá màn hình cho Ubuntu, tích hợp bộ trộn âm thanh đi ngủ. Viết bằng Rust (Tauri 2).

> Đang phát triển.

## Nguồn âm thanh & hình ảnh

* **Âm thanh nền & Sóng não (32 tệp):** từ dự án mã nguồn mở [remvze/moodist](https://github.com/remvze/moodist).
* **Nhạc Lo-Fi (23 bản):** từ [btahir/open-lofi](https://github.com/btahir/open-lofi), phát hành theo giấy phép **CC0 1.0 Universal (Public Domain)**.
* **Tiếng ồn nâu / hồng / trắng:** tổng hợp trực tiếp bằng Rust trong `src-tauri/src/audio/decoder.rs`.
* **Ảnh minh hoạ thẻ âm thanh:** từ [riccardobertolini/lofi-music](https://github.com/riccardobertolini/lofi-music).

Chi tiết danh sách tệp xem tại [ui/sounds/CREDITS.md](ui/sounds/CREDITS.md).
